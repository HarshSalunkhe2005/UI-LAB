# Examples

Three worked examples from real runs of this skill against the evaluation briefs. Each has the brief, the Gate 2 table, the direction card, a code excerpt, the audit script's real output and a text description of the first screen (no images are shipped).

| File | Mode | What to learn from it |
|---|---|---|
| 02-ferry-dashboard.md | Build | replacing a default house style on a dense dashboard, one accent with one meaning |
| 04-restaurant-site.md | Build | taking the system from the place, a world adapted instead of copied |
| 08-redesign-orbit.md | Redesign | keeping content and order while changing every visual choice |

Read one when the brief is close to it. They show the shape of the artifacts, not a style to copy.
