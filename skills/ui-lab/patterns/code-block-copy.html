Parsing and formatting

Parse a string with an explicit format, then format it back out.

JavaScript
import { parse, format } from 'quill'

const d = parse('14/03/2027', 'DD/MM/YYYY')
format(d, 'D MMMM YYYY') // "14 March 2027"

Gotcha

Without a format, parse reads 03/04/2027 as month first. Always pass a format for non-ISO strings.

Format tokens
TokenOutput
YYYY2027
MMMMMarch
D14
