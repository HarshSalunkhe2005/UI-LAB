# Anti-slop: defaults to avoid unless the brief earns them

Seed list. The full catalogue (30+ entries with "why it reads as AI" and "do instead") is a later addition; this file is where it will live.

## 2023-era defaults
- Purple-to-blue gradient wash on the hero, or gradient text on headings.
- Emoji or unicode symbols as feature icons.
- A row of three identical icon-tile, heading, sentence cards.
- Pill buttons with a coloured glow shadow; cards that lift on hover everywhere.
- A hero metric row used as filler; "Trusted by 10,000+ teams" with placeholder logos.

## Convergent defaults (the current house style)
- Cream or off-white ground, a heavy display serif with one italic accent word in a warm colour, a mono eyebrow label, a rotated "sample" stamp.
- Dark navy or slate dashboard with blue and amber accents and a donut chart.
- A bento grid of unequal rounded tiles as the feature section.
- Marquee ticker strips used as decoration.
- Numbered section labels ("01 / How it works") without meaning.

## How to use this list
A match is not a ban. It is a prompt to ask: did the brief, the audience or the product choose this, or did it arrive by default? If the answer is "by default", change it and write what you changed in the direction card.
