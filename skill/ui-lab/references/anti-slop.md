# Anti-slop: defaults to leave unless the brief earns them

Used at Gate 2. A match is not a ban. It is a question: did the brief, the audience or the product choose this, or did it arrive by default? If by default, change it.

## How to run the check

1. Write the page you would build without thinking, one line per axis (ground, type voice, layout grammar, accent strategy, motion).
2. Mark every line that matches an entry below (sections A to D).
3. Write two candidate directions, pick one, and make sure it differs from the default on at least three axes, using the alternatives menu at the end. Each change needs a reason from the brief. Then check section D: the menu's obvious picks are now defaults too.
4. Where you keep a default, write the evidence that earns it.

## A. Convergent defaults (the current house style)

These are what an agent produces when it is trying to avoid the older slop. They read as "AI" to anyone who has seen a dozen.

| # | Default | Why it reads as AI | Instead |
|---|---|---|---|
| A1 | Cream or off-white ground with a heavy display serif and one italic accent word in a warm colour | The same recipe on every "tasteful" page; the italic word is a tic | Choose type from the subject (a grotesque, a slab, a mono, a condensed face, a humanist) and let emphasis come from weight, size or position |
| A2 | Mono eyebrow label above every heading | Decorative metadata with no information | Delete it, or use a label only where it carries a fact (date, version, section name users search for) |
| A3 | Rotated stamp or sticker ("SAMPLE", "NEW", "BETA") and hard offset shadows | Neo-brutalism as garnish | One strong object that belongs to the product (a real artefact, a live fragment of the UI) |
| A4 | Marquee ticker strip | Motion for its own sake, usually repeating the hero | Static proof (a real quote, a number with its source) or nothing |
| A5 | Numbered section labels ("01 / How it works") | Looks structured, carries no meaning | Plain headings; number only genuine steps |
| A6 | Dark navy/slate dashboard, blue plus amber accents, donut chart, KPI tile row | The default "analytics" skin | Pick ground by working conditions (a 7am glance, a control room, a printout); one accent for "needs action"; bars and lines over donuts |
| A7 | Bento grid of unequal rounded tiles as the feature section | Reads as a template | Features as a table, a narrative with one annotated screenshot, or a before/after |
| A8 | Serif plus warm orange on charcoal for any food or hospitality brief | Hospitality cliché | Take colour and type from the place: its material, signage, menu card, region |
| A9 | Three-up "how it works" with big numerals | The numerals do the work the copy should do | Show the real product moment for each step |
| A10 | Pricing with the middle tier scaled up and badged "Most popular" | Everyone's pricing page | Say who each plan is for in the plan's own terms |
| A11 | Tags/pills for every piece of metadata | Visual noise, flat hierarchy | Plain text with a clear separator; pills only for filters that act |
| A12 | Hero: eyebrow, huge headline, subline, two buttons (primary and ghost), tiny reassurance line | Interchangeable | Lead with the product's own evidence: a working fragment, a number, a sentence only this product can say |

## B. 2023-era defaults (still common)

| # | Default | Instead |
|---|---|---|
| B1 | Purple-to-blue gradient wash, or gradient text on headings | A flat, chosen colour; weight and size for emphasis |
| B2 | Emoji or unicode symbols as feature icons | Drawn SVG icons from one set, or no icons |
| B3 | A row of three identical icon-tile, heading, sentence cards | Vary the form by content: one large, two small; or a list |
| B4 | Pill buttons with a coloured glow; cards that lift on hover everywhere | Flat buttons, hover that changes one property, no glow |
| B5 | A hero metric row as filler ("10,000+ users", "99.9% uptime") | Metrics only if real, sourced and relevant to the decision |
| B6 | "Trusted by" row of placeholder logos | Real names, or a specific quote with a role |
| B7 | Glassmorphism cards on a gradient | Solid surfaces with a clear border or tone step |
| B8 | Identical fade-up on every block as you scroll | Animate one thing that explains something |
| B9 | Inter at every size and weight, no scale | A chosen pair and a real scale |
| B10 | Centred everything, one column, equal section padding | Alignment on a grid, density that varies between sections |
| B11 | Cards inside cards, each with shadow and radius | One level of container |
| B12 | Generic copy: "Unlock the power of...", "seamless", "supercharge", "next level" | The specific thing the product does, in the voice of the audience |

## C. Dense-UI defaults

| # | Default | Instead |
|---|---|---|
| C1 | Table that is clipped or side-scrolls blindly at 375 | Stacked rows or a column-priority table with an obvious affordance |
| C2 | Colour as the only status signal | Text or icon plus colour |
| C3 | Every KPI the same size | One or two lead figures, the rest small, each against a target or yesterday |
| C4 | Donut chart with five or more slices | Sorted horizontal bars with direct labels |
| C5 | System font at 14px for everything | A chosen text face with tabular figures for numbers, a scale of 12 to 20 |

## D. Defaults this procedure itself produces (observed)

When agents avoid sections A to C using the menu below, they tend to land on the same new place. Treat these as defaults too.

| # | Default | Instead |
|---|---|---|
| D1 | Cool grey or pale paper ground, ink text, one vermilion/red accent used only for action, and nothing else | Choose the accent logic from the product (a colour field, two close hues, colour from the content), and let at least one section carry a strong ground of its own |
| D2 | Monospaced labels and numbers as the "data" voice, plus a grotesque display | Let numerals and labels share the text face with tabular figures; use mono only where the content is literally code or an identifier |
| D3 | A "ledger / report / newsroom / departure board" metaphor with hairline rules everywhere | Take the metaphor from a different material of the product's world, or use no metaphor and let one strong object carry the page |
| D4 | Left-aligned hero with a product fragment on the right, then ruled tables for every section | Change the form of at least two sections (a full-bleed colour band, a large quote, an annotated screenshot, a single figure) |
| D5 | Austerity as the whole idea: no imagery, no colour fields, no scale contrast | Spend restraint deliberately: one place of real visual weight per screen, and rhythm changes down the page |

## Alternatives menu, per axis (use to choose, not to copy)

**Ground:** warm paper; cool neutral light; mid-tone flat colour as the whole page; deep dark with one lit surface; photographic or illustrated field; high-contrast black on white with no tint; a tinted ground borrowed from the product's material (kraft, blueprint, terminal, signage).

**Type voice:** grotesque with tight tracking; humanist sans; slab or Clarendon-style serif; condensed display; monospaced as the main voice; geometric with a distinct numeral set; a text serif used small and set long; all-lowercase or all-caps as a system. The display face and the text face should do different jobs.

**Layout grammar:** asymmetric two-column with an offset; full-bleed sections with a fixed rail; a table or ledger as the structure; a single long column like an article with margin notes; a grid with visible rules; split screen; one oversized object and small supporting text; a sidebar-driven app shell for tools.

**Accent strategy:** none (ink only) with one highlight in the data; a single saturated colour used only for action; two close hues; a signal colour reserved for "needs attention"; colour from the content (photos, product) rather than from the interface.

**Motion:** none except state changes; one choreographed entrance; scroll that reveals a process; hover that shows information; physics on one object; page transitions only. Always honour reduced motion.
