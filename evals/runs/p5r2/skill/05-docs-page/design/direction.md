# Direction (docs page, Quill "Parsing and formatting")
Brief (assumed, no one to ask): audience = JS developers mid-task, looking up a token or a gotcha; job = find and read fast; mood = exact, plain, confident; memorable moment = token table you can filter; must not feel like a dark-terminal docs template.
Roll: clock 1793436258 -> last digit 8 mod 6 = 2 (Machine and Signal). A = 3 Technical Dark (fits dev docs). B = next fitting family, Instrument and Spec: 7 Swiss Grid.
Default (unthought): ground = white/dark navy; type = Inter + mono; layout = 3-col docs; accent = blue links; motion = none. Matches A10, B12, D1, D2.
Chosen: Swiss Grid adapted (A is the dev-docs default, B12). Reason: reading + findability, clarity is the pitch; ink on white, ruled grid, no radius.
Differs on: ground (white + black code slabs), type (Schibsted Grotesk, mono only for code), accent (signal yellow #ffd60a as highlighter, never as text colour on white), layout (visible rules, 1-col reading measure).
Boldest element: 4rem h1 under a 6px rule. Rhythm: white prose -> black code slabs -> grey-raised token table panel -> yellow gotcha callouts.
Patterns adapted: toc-scrollspy, code-block-copy, sidebar-app-shell (nav drawer at 375).
Refusals: no rounded corners/shadows; no second accent; no mono eyebrow labels.
