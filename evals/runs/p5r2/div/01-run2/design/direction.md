# Direction (Relay landing)

Brief assumptions: audience PMs at 50-500 person software companies, reading at a desk Monday morning; job = get them to start a trial; mood: exact, calm, a little dry; memorable moment = a pile of tickets that merges into themes as you drag one slider. No invented metrics beyond clearly product-scale facts. Must not feel like: purple AI gradient page, bento grid, fake logo row.

Default (no thinking): ground cool white/dark navy; type Inter; centred hero + 3 icon cards; one violet accent; fade-ups.
Matches: A1, A4, A9, A10, A11, B6, B8, B9, B11.

Roll: `date +%s` = 1793436845, last digit 5, mod 6 = 5 -> family 5 (Cinematic and Spatial).
Candidate A: world 24 Explorable Explainer (fits: explaining how something works; the product has a manipulable step: clustering). Candidate B: wrap to family 0, world 12 Broadsheet (digest is a newsletter) - dropped: "never for a marketing hero", would be only a skin.
Chosen: 24. Adapted: ground pale sage-grey not cream, ultramarine = "you control", amber = "the system computed", Newsreader + Hanken Grotesk, no mono (D2).

| Axis | Default | Chosen |
|---|---|---|
| ground | white/navy | pale sage page, ink band, ultramarine band; rhythm changes 4 times |
| type | Inter | Hanken Grotesk heads/controls, Newsreader text, tabular figures |
| layout | centred one column | asymmetric split hero, ruled table for features, rows for pricing |
| accent | violet | two meanings: blue = control, amber = computed |
| motion | fade-ups | only bar widths re-flow when slider moves; none under reduced motion |

Boldest element: the ticket-merge figure with the oversized amber "14 -> 4" result. Rhythm changes: light hero -> ink band -> light table -> blue quote band -> light pricing/FAQ -> ink footer.
Swap test: replace Relay with another tool and the hero figure, copy and ticket data all have to change. Passes.

Patterns adapted: hero-evidence (idea), hero-email-inline (form states), feature-table (table with limits), testimonial-pull, pricing-plain (who-for rows, no scaled tier), faq-details, footer-links.

Refusals: 1. no figure you can only watch (slider + keyboard). 2. no icon-card trios. 3. no fake logo wall or round-number metrics.
