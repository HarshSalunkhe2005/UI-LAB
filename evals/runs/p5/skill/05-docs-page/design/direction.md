# Direction
Default: white/grey ground, Inter, 3-col docs shell, indigo accent, uniform spacing.
| axis | default | candidates | chosen |
|---|---|---|---|
| ground | white | Technical Dark (Machine) / Broadsheet (Paper) | newsprint paper, dark code bands |
| type | Inter | Newsreader + Libre Franklin + JetBrains Mono for code only | serif prose, sans UI |
| layout | 3-col | same, ruled | 3-col with rules, headings on 2px rules |
| accent | indigo | teal ink; amber reserved for gotcha | teal + amber signal |
| motion | fade | none | scrollspy + copy state only |
Chosen: World 12 Broadsheet (Paper and Print), over World 3 Technical Dark: reading is the job. Tokens adapted (teal accent, no red, dark code bands for rhythm). Swap test: passes via serif prose + ruled sections + amber callout. Patterns: none adapted (patterns/INDEX not opened; disclosed).
