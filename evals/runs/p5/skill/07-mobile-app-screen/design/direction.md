# Direction
| Axis | Default | Match | Candidates | Chosen |
|---|---|---|---|---|
| ground | light/white card UI | A-class generic | Soft Playful (cream pastel) / Hi-Fi Deck (dark tangible) | dark green-black |
| type | Inter | A10 | Bricolage Grotesque display + Instrument Sans | chosen pair |
| layout | stacked white cards | B6/A12 | one loud slab + flat list rows | slab then list |
| accent | purple | A1 | amber (tally/ink) + lime for done | amber + lime |
| motion | fade-up | A9 | press scale, tick draw, streak bump (all state changes) | state-only |
Worlds: Soft Playful (Soft and Living) vs Hi-Fi Deck (Instrument/tangible); took Hi-Fi's tactile controls with own tokens. Rhythm: amber slab vs dark list, scale 112px numeral vs 16px rows. Patterns adapted: none fitted (mobile app shell, status-chips idea for state). Refusals: no gradients, no emoji icons, no hover-lift cards.
