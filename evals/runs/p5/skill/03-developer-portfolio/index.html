Each one started with a screen that was slow, inaccessible or both. Client names are withheld where contracts ask for it. The numbers come from their own monitoring, not mine.

2024, 5 months, port logistics

Container tracking grid

React, TypeScript, virtualised rows, ARIA grid

Problem
Planners filtered a 40,000-row manifest by pasting into a spreadsheet, because the web grid froze for two seconds on every keystroke and could not be used without a mouse.
What I did
Rebuilt the grid with windowed rows and filtering off the main thread. Wrote the keyboard model as a spec first, then tested it with NVDA and VoiceOver users on the planning team.
Outcome
Filter response went from 2.1 s to 90 ms. The spreadsheet workaround was retired in March.

2023, 3 months, diagnostics

Lab results, made auditable

Vue, WCAG 2.2 AA remediation, axe in CI

Problem
A results portal for clinicians failed a procurement accessibility review. Reference ranges were conveyed by colour alone and the date picker trapped focus.
What I did
Triaged 212 findings by who they stopped from working, not by count. Replaced the picker, gave every flag a word and a shape, and put axe and a keyboard test into the pipeline so it stays fixed.
Outcome
Open issues fell from 212 to 9, all minor. The portal passed the second review and the contract renewed.

  • After9

2022, 4 months, energy trading

Live price charts with a table behind them

Canvas, Web Workers, WebSocket, TypeScript

Problem
Traders watched 60 price series on charts that redrew the whole canvas on every tick. Laptops stalled, and the charts offered nothing to a screen reader.
What I did
Drew only the changed region, batched ticks per frame, and put the same data in a sortable table one key away. The chart announces thresholds crossed, not every tick.
Outcome
Frame time dropped from 48 ms to 9 ms with all 60 series live. Two traders now use the table view by choice.
  • Before48 ms
  • After9 ms

2021, 2 months, public statistics

Statistics portal that works on a phone

HTML, CSS, a little JavaScript, no framework

Problem
Forty-odd wide tables were clipped on mobile, and 61% of the agency's visitors arrive on one. Journalists were screenshotting numbers instead of linking them.
What I did
Redesigned the tables around column priority: the columns that answer the question stay, the rest fold into a row detail. Every table got a stable URL and a CSV link.
Outcome
Mobile bounce rate on table pages fell from 71% to 38%. Direct table links in press coverage went from rare to routine.

  • After38%
